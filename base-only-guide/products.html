Products tab

Submit products · request approval · check the list

This page has two sides: Submit Form Here !! on the left, and Record List on the right. Add products with a creator affiliate, then send an approval request by selecting those products.

Page layout

Left — Submit Form Here !!

  • Product Submit — add a new product
  • Sent Approval — send products for HQ approval

Right — Record List

  • Product List — products you added
  • Approval Request — submissions sent to HQ

1 · Product Submit

Use this to add products linked to a creator affiliate.

  1. On the left panel, open the Product Submit tab.
  2. Fill the Product Submission form:
    • URL — product listing link
    • Image — product image (paste / drag / upload)
    • Internal Code — SKU / internal code
    • Product Name, Price, and other fields as needed
    • Creator — pick the affiliate creator (e.g. Sofea Skin)
  3. Submit the form.
  4. Confirm it appears on the right under Record List → Product List. You can filter by creator chips (Aina Beauty, Maya Lifestyle, Nina Glow, etc.).
Tip: Always set Creator when you submit. Empty or wrong creator makes HQ and Warehouse tracking harder.

2 · Sent Approval

When products are ready, send them to HQ for approval.

  1. On the left panel, switch to the Sent Approval tab.
  2. Fill the Affiliate Approval form:
    • Submission Title — one clear request name (e.g. Creator + platform + date)
    • Selected Products (Link) — pick one or more products from Product Selection
    • Add notes if HQ needs context
  3. Submit the form.
  4. Confirm it appears on the right under Record List → Approval Request with Status Pending Approval.
Done when: your request shows in Approval Request (e.g. Lee-Tiktok-28July) with Selected Products linked and Status = Pending Approval. HQ will review it next.

3 · Record List (check your work)

Product List

  • See every product you submitted
  • Filter by creator, sort, or search
  • Check image, URL, SKU, price, Title Ads, Creator

Approval Request

  • See requests you already sent
  • Check Selected Products, Submitter, Status
  • Pending Approval means waiting for HQ

Quick checklist

Before Product Submit

  • URL + image ready
  • Internal code / SKU set
  • Creator affiliate selected

Before Sent Approval

  • Clear submission title
  • Correct products selected
  • Prefer one creator per request
