Bulk Import (grid view)

Use the Bulk Import grid when you have many products in Excel or a Lark Sheet.

  1. Open the Products tab → Bulk Import grid view.
  2. In Excel or the test Lark Sheet, copy detail rows only (do NOT include the header row).
  3. In the grid, click the Image cell on the first empty row (the + cell).
  4. Paste (Ctrl+V / Cmd+V). All columns from Image onward fill in at once.
  5. Columns pasted (Image → Title Ads):
    • Image — leave blank or paste image later
    • URL — listing link
    • Internal Code — SKU
    • Product Name
    • Price — e.g. RM49.90
    • Title Ads — Yes or No
  6. PID is auto — do not paste into that column.
  7. Set Creator after import if the grid view is filtered by creator, or link creator on each row as needed.
Test sheet: Use the shared Lark Sheet Panda Eyes — Bulk Import Test (open sheet). Copy rows 2–4 (details only) and paste into Image cell to test.
Notifications: Each new row with a Product Name triggers PE-N1 (New product) to the ops group — bulk paste may send one message per row. Check PandaEyes_Test chat after import.

1 · Product Submit

Use this to add products linked to a creator affiliate.

  1. On the left panel, open the Product Submit tab.
  2. Fill the Product Submission form:
    • URL — product listing link
    • Image — product image (paste / drag / upload)
    • Internal Code — SKU / internal code
    • Product Name, Price, and other fields as needed
  3. Submit the form.
  4. Confirm it appears on the right under Record List → Product List. You can filter by creator chips (Aina Beauty, Maya Lifestyle, Nina Glow, etc.).
Tip: Creator is set later on Sent Approval, not on each product row. Bulk import works without Creator.

2 · Sent Approval

When products are ready, bundle them for HQ. Pick the Creator here — you do not need Creator on each product row first.

  1. On the left panel, switch to the Sent Approval tab.
  2. Fill the Affiliate Approval form:
    • Creator — select the affiliate (e.g. Aina Beauty, Sofea Skin) — this is the main identifier for the submission
    • Selected Products (Link) — pick one or more products from Product Selection (no Creator needed on products yet)
    • Add Approval Notes if HQ needs context
  3. Submit the form. Creator is stamped onto all selected products automatically.
  4. Confirm it appears on the right under Record List → Approval Request with Status Pending Approval.
Done when: your request shows in Approval Request with the correct Creator and linked products. HQ will review it next.

3 · Record List (check your work)

Product List

  • See every product you submitted
  • Filter by creator, sort, or search
  • Check image, URL, SKU, price, Title Ads, Creator

Approval Request

  • See requests you already sent
  • Check Selected Products, Submitter, Status
  • Pending Approval means waiting for HQ

Quick checklist

Before Product Submit

  • URL + image ready
  • Internal code / SKU set
  • Product name + price filled

Before Sent Approval

  • Creator selected
  • Correct products selected
  • One creator per submission
